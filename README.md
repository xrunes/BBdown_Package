# BBdown_Package

[BBDown](https://github.com/nilaoda/BBDown)打包自助版，帮助亲朋好友不会配置ffmpeg路径以及不会命令行的人简单使用BBDown的解决方案

当前BBDown Version: 1.6.4（修复登录问题）

当前ffmpeg Version: 9.0.2

使用方法：

在[Release](https://github.com/xrunes/BBdown_Package/releases)中下载压缩包并解压

双击**bat**文件，粘贴B站视频链接即可下载视频

- **BBDown_Default.bat**：下载画质和音质最高的文件，下载的文件最大，同时画质也最好，但下载速度偏慢

- **BBDown-Speed.bat**：下载画质和音质最低的文件，下载的文件小，速度快，但画质较低
